# تشغيل أندرويد والتجهيز للنشر

## تجربة النسخة

حمّل ملف APK الناتج من GitHub Actions وثبّته على جهاز أندرويد. التطبيق يستهدف
Android SDK 36، والحد الأدنى Android 7 (API 24)، لكنه يحتاج Android System
WebView حديثًا. جرّبه أولًا على جهازك الفعلي؛ نسخة الاختبار لم تُختبر على هاتف حقيقي.

اللعبة أفقية وتعمل دون إنترنت بعد التثبيت. حرك العصاية اليسار لتوجيه العربية،
واضغط N₂O للنيترو وBRAKE للفرامل. التسارع تلقائي. لديك ثلاث اصطدامات تقريبًا قبل
نهاية الجولة؛ تجاوز قريب من السيارات يمنح عملات وشحن نيترو.

## فتح الإعلانات لاحقًا

الإعلانات مغلقة في الإصدار الحالي. لا توجد أرباح فعلية قبل ربط حسابك وضبطه.

1. أنشئ تطبيق أندرويد في AdMob وسجّل معرّف التطبيق ووحدة إعلان مكافأة.
2. انسخ `.env.example` إلى `.env` واضبط `VITE_ADS_ENABLED=true`.
3. أثناء التطوير اترك `VITE_ADMOB_TEST_MODE=true` واستخدم معرّفات Google التجريبية.
4. للإنتاج استبدل `com.google.android.gms.ads.APPLICATION_ID` في AndroidManifest
   بمعرّف تطبيقك، و`VITE_ADMOB_REWARDED_ID` بمعرّف وحدة إعلان المكافأة، ثم اضبط
   `VITE_ADMOB_TEST_MODE=false` فقط عند جاهزية نسخة الإنتاج.
5. اضبط رسالة موافقة المستخدمين في AdMob واختبر مسار UMP وخيارات الخصوصية.
6. حدّث سياسة الخصوصية وبيانات Data safety حسب سلوك النسخة الفعلي والـSDK.

واجهة الإعلانات تبدأ بمراجعة الموافقة قبل التهيئة والتحميل. لا توضع مفاتيح
الذكاء الاصطناعي أو أي مفاتيح سرية داخل التطبيق. هذه اللعبة لا تستدعي موقع MAZ
أثناء اللعب، وبالتالي لا تستهلك رصيد نماذج لكل لاعب.

## إصدار Google Play

- اختر معرف حزمة نهائيًا قبل أول نشر: الحالي `com.mazvix.neonrush`.
- جهّز مفتاح توقيع خاصًا بك واحتفظ بنسخة آمنة خارج GitHub. لا ترفعه للمستودع.
- من Android Studio أنشئ Signed App Bundle بصيغة AAB للإنتاج.
- اختبر نسخة Release على أجهزة فعلية، وراجع اللمس والصوت والخلفية والحفظ والأداء.
- أضف صور المتجر ووصفًا دقيقًا وتصنيف المحتوى وإقرار الإعلانات وسياسة خصوصية عامة.
- راجع متطلبات الاختبار والنشر وTarget SDK الظاهرة في Play Console وقت التقديم.

هذه تجهيزات للنشر وليست ضمانًا لقبول المتجر. الإصدار الحالي نموذج قابل للعب،
ويحتاج تجربة وموازنة وتحسينات قبل التسويق كلعبة تجارية مكتملة.
